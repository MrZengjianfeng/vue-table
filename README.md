# vue Table

Vue 3 + Vite + TypeScript + Ant Design Vue 后台管理项目。

## 技术栈

- Vue 3
- Vite
- TypeScript
- Ant Design Vue 4
- Vue Router
- Pinia

## 启动

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:5174`

演示账号：`admin` / `admin123`

## 功能

- 登录鉴权与路由守卫
- 侧边栏 + 顶栏后台布局
- 用户管理（表格内表单编辑、新增 / 保存 / 删除）
